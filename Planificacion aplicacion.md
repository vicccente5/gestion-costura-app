Actúa como un desarrollador de software experto (Tech Lead). Quiero crear el backend y la lógica central de una aplicación móvil para la gestión de un taller de costura. El desarrollo debe hacerse en Go (Golang) para asegurar alto rendimiento y rapidez, utilizando PostgreSQL como base de datos relacional y GORM como ORM.

Descripción de la App:
La aplicación es una herramienta integral para que una costurera pueda administrar sus finanzas (ingresos y gastos), controlar su inventario de materiales de costura y calcular con precisión los costos y el margen de ganancia real de cada prenda o arreglo que realiza.

Funciones Principales:

Inventario de Materiales: Registrar materiales (telas, hilos, botones), stock disponible, unidad de medida, costo total de compra y cálculo automático del costo por unidad/medida.

Gestión de Trabajos: Crear un encargo, asignarle los materiales exactos que se ocuparán, establecer un precio de venta final a la clienta y calcular automáticamente la rentabilidad neta.

Flujo de Caja: Registro de ingresos, gastos generales del taller y balance mensual.

Metodología de Trabajo:
Por favor, guíame para desarrollar este proyecto en Go dividiéndolo en fases claras y ordenadas.

Fase 1: Arquitectura del proyecto y modelado de las estructuras de datos (Entities/Models) utilizando GORM para prepararlas para PostgreSQL.

Fase 2: Configuración de la conexión a PostgreSQL y desarrollo de la lógica de negocio (Cálculos de inventario y finanzas).

Fase 3: Creación de los endpoints (API REST) para manejar las operaciones CRUD.

Fase 4: Optimización y concurrencia (goroutines) si es necesario.

Para empezar, entrégame únicamente el paso a paso detallado y el código inicial de la Fase 1.
